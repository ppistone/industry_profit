## 一、项目简介
一个**零依赖纯静态**网页看板，展示国家统计局「全国规模以上工业企业利润」月度发布中 **42 个工业行业（总计 + 41 个大类）** 的财务指标：
- 营业收入、营业成本、利润总额（单位：亿元）
- 数据区间：2024 年 1—2 月 ～ 2026 年 9 月（累计口径，共 30 期）
- 支持**累计值**（统计局原始口径）与**单月值**两种视图切换

数据源：国家统计局《全国规模以上工业企业利润》月度发布（https://www.stats.gov.cn/sj/zxfb/）。

## 二、数据口径（务必理解，避免误读）
1. **累计值**：统计局只发布累计值（1—2 月、1—3 月……12 月），这是官方原始口径。
2. **单月值推算**：
   - 每年 **1 月、2 月**各自取当年 1—2 月累计值的一半（如 2026 年 1—2 月累计 16316.5，则 1 月 = 2 月 = 8158.25）；
   - **3 月及以后** = 相邻两期累计之差（差分推算）。
   - 除 1/2 月外，单月值非官方单月统计，仅供趋势参考。
3. **同比（YoY）**：= 本年同期 ÷ 上一年同期 − 1；首年（2025 年 1—2 月 / 1 月）无上年同期数据，留空。
4. **着色规则（中国习惯）**：涨 = 红，跌 = 绿。同比为负 → 绿色显示（数值与同比% 均绿），为正 → 红色。
5. **行业释义**依据《国民经济行业分类》（GB/T 4754-2017，2019 年修订），含大类代码与门类。
6. 石油、煤炭及其他燃料加工业部分期次上年同期为亏损，同比不可比（统计局注）。

## 三、页面功能清单
| 功能 | 说明 |
|------|------|
| 行业列表 + 切换 | 左侧 42 个行业，鼠标点击，**或键盘 ↑/↓ 切换**，右侧自动刷新 |
| 视图切换 | 顶部「累计值 / 单月值」切换，切换行业不重置当前视图 |
| 三图组合 | 利润总额 / 营业收入 / 营业成本各自独立折线 + 同比柱状组合图（双轴，红涨绿跌） |
| 数值直标 | 折线点上方直接标注每月数值，柱顶标注同比%，无需悬停 |
| 即时悬浮提示 | 鼠标移到数据点即时显示「期间 + 数值 + 同比」（自定义浮窗，无系统延迟） |
| 指标卡片 | 右侧顶部三张卡（营收/成本/利润最新期数值 + 同比），数值跟随同比正负变色 |
| 明细表 | 含三列同比（红涨绿跌），数值单元格同样按同比着色 |
| 代表公司 | 每行业列举 A 股 / 港股龙头（代码 + 名称，纯知识整理，非投资建议） |
| 联系作者 | 右侧悬浮按钮，悬停（触屏点击）弹出公众号二维码 |

## 五、如何更新 / 改版
详见 [`UPDATE_GUIDE.md`](./UPDATE_GUIDE.md)，要点：
- **数据更新**：`python update.py`（自动翻页抓新期次、仅向前追加、重生成并 git 推送）。
- **改版**：只改 `template.html`，然后 `python update.py`（或手动重生成 index.html）并推送。
- 铁律：**永远只改 `template.html`，`index.html` 一律由脚本生成**，避免两边手工改造成漂移。
- 提交后 GitHub Pages 通常 1–3 分钟重建生效。

### B 看板（非工业）如何填数据 / 改版
- **填数据**：在 `nonindustrial_template.csv` 按列填写每个行业各年度的「营业收入(亿元) / 净利润(亿元) / ROE(%)」（留空＝暂无数据），然后运行 `python csv_to_json.py`——脚本会覆盖 `nonindustrial_data.json` 并重新生成 `nonindustrial.html`。
- **改版**：只改 `nonindustrial_template.html`，再运行 `python csv_to_json.py`（或手动重生成 `nonindustrial.html`）。
- 当前 `nonindustrial_data.json` 含部分示例/占位数据（银行、房地产、农林牧渔为示意数字，其余为空），用于演示框架；填好真实数据即覆盖。
- 口径说明：B 看板为**上市公司代理**（申万一级行业汇总），仅覆盖 56 个非工业大类中"有上市公司代表"的部分，不等同于全行业普查。
